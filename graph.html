CHUYÊN ĐỀ ĐỒ THỊ CƠ BẢN

GRAPH THEORY & ALGORITHMS

I. Định Nghĩa Và Các Thành Phần Cốt Lõi

Một đồ thị G = (V, E) là một cấu trúc dữ liệu trừu tượng. Trong đó:

  • V (Vertices): Tập hợp các điểm được gọi là đỉnh. Số lượng đỉnh ký hiệu là |V| hoặc n.
  • E (Edges): Tập hợp các cặp đỉnh nối với nhau. Số lượng cạnh ký hiệu là |E| hoặc m.

1. Phân loại đồ thị sâu hơn

A. Đơn đồ thị (Simple Graph): Giữa hai đỉnh bất kỳ chỉ có tối đa một cạnh nối và không có "khuyên" (cạnh nối đỉnh với chính nó).

B. Đa đồ thị (Multigraph): Cho phép có nhiều cạnh nối giữa cùng một cặp đỉnh. Điều này thường xuất hiện trong các bài toán mạng giao thông (nhiều con đường giữa 2 thành phố).

C. Đồ thị có hướng (Directed Graph): Các cạnh có chiều xác định. Cạnh (u, v) khác hoàn toàn cạnh (v, u).

2. Bậc và các định lý liên quan

Trong đồ thị vô hướng, Bậc của đỉnh v ký hiệu là deg(v).

Định lý bắt tay: Tổng bậc của tất cả các đỉnh luôn bằng 2 lần số cạnh (vì mỗi cạnh đóng góp 1 bậc cho mỗi đầu mút).

Trong đồ thị có hướng:

  • Bán bậc vào (In-degree): Số cung đi vào đỉnh.
  • Bán bậc ra (Out-degree): Số cung đi ra khỏi đỉnh.

II. Kỹ Thuật Lưu Trữ Và Tối Ưu Bộ Nhớ

Mỗi cách biểu diễn dưới đây đều có ưu và nhược điểm riêng, việc chọn sai có thể dẫn đến lỗi Memory Limit Exceeded hoặc Time Limit Exceeded.

1. Ma trận kề (Adjacency Matrix)

Sử dụng mảng hai chiều A[V][V]. Nếu có cạnh từ u đến v thì A[u][v] = 1.

Dùng khi số cạnh lớn (đồ thị dày), cần kiểm tra nhanh xem u và v có nối nhau không trong thời gian O(1).

2. Danh sách kề (Adjacency List)

Sử dụng một mảng các vector hoặc list. Mỗi dòng adj[u] chứa danh sách các đỉnh kề với u.

Đây là cách phổ biến nhất trong lập trình thi đấu vì chỉ tốn O(V + E) bộ nhớ.
Khai báo danh sách kề C++
vector<int> adj[100005]; // Mảng các vector để lưu danh sách kề
void addEdge(int u, int v) {
    adj[u].push_back(v);
    adj[v].push_back(u); // Nếu là đồ thị vô hướng
}

III. Thuật Toán Duyệt Theo Chiều Rộng (BFS)

BFS (Breadth-First Search) hoạt động dựa trên nguyên lý "loang". Từ một đỉnh gốc, ta thăm tất cả các đỉnh kề nó, sau đó mới thăm các đỉnh xa hơn một mức.

Giải thích cơ chế:

  1. Sử dụng một hàng đợi Queue để quản lý các đỉnh sắp được thăm.
  2. Sử dụng mảng visited[] để đảm bảo mỗi đỉnh chỉ bị thăm một lần (tránh vòng lặp vô tận).
  3. Độ phức tạp: O(V + E).
Lưu ý quan trọng: BFS luôn tìm được đường đi ngắn nhất giữa hai đỉnh trên đồ thị KHÔNG có trọng số.
BFS_Algorithm.cpp
void bfs(int start, int n) {
    queue<int> q;
    q.push(start);
    visited[start] = true;

    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adj[u]) {
            if (!visited[v]) {
                visited[v] = true;
                dist[v] = dist[u] + 1; // Tính khoảng cách
                q.push(v);
            }
        }
    }
}

IV. Thuật Toán Dijkstra Nâng Cao

Đây là thuật toán "vàng" để tìm đường đi ngắn nhất trên đồ thị có trọng số không âm. Nó hoạt động theo cơ chế tham lam (Greedy).

Giải thích cặn kẽ:

Tại mỗi bước, thuật toán chọn một đỉnh u có khoảng cách từ nguồn là nhỏ nhất trong số các đỉnh chưa được "tối ưu hóa" hoàn toàn. Sau đó, nó thực hiện Thư giãn (Relaxation) cho các cạnh đi ra từ u.

Phép thư giãn: Nếu dist[v] > dist[u] + weight(u, v) thì cập nhật dist[v] = dist[u] + weight(u, v).
Dijkstra_PriorityQueue.cpp
typedef pair<long long, int> pll;
void dijkstra(int s, vector<pair<int, int>> adj[]) {
    priority_queue<pll, vector<pll>, greater<pll>> pq;
    fill(dist, dist + n, 1e18); // Khởi tạo vô cùng
    dist[s] = 0;
    pq.push({0, s});

    while (!pq.empty()) {
        long long d = pq.top().first;
        int u = pq.top().second;
        pq.pop();

        if (d > dist[u]) continue;

        for (auto edge : adj[u]) {
            int v = edge.first, w = edge.second;
            if (dist[v] > dist[u] + w) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
}

V. Thuật Toán Kruskal Và Cấu Trúc DSU

Bài toán Cây khung nhỏ nhất (MST) yêu cầu chọn ra V - 1 cạnh sao cho tổng trọng số là nhỏ nhất và tất cả các đỉnh đều liên thông.

Tại sao dùng Kruskal?

Kruskal cực kỳ hiệu quả cho đồ thị thưa. Ý tưởng là sắp xếp toàn bộ cạnh theo trọng số tăng dần, sau đó lần lượt chọn cạnh nếu nó không tạo ra chu trình.

Để kiểm tra chu trình cực nhanh, ta sử dụng DSU (Disjoint Set Union) với kỹ thuật nén đường.
Kruskal_MST.cpp
struct Edge { int u, v, w; };
bool cmp(Edge a, Edge b) { return a.w < b.w; }

int find(int v) {
    return (v == parent[v]) ? v : parent[v] = find(parent[v]);
}

void solveMST() {
    sort(edges.begin(), edges.end(), cmp);
    for (Edge e : edges) {
        int rootU = find(e.u);
        int rootV = find(e.v);
        if (rootU != rootV) {
            totalWeight += e.w;
            parent[rootU] = rootV; // Hợp nhất
        }
    }
}
